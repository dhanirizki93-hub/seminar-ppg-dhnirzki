## 🚀 Cara Menjalankan Website di Localhost

Ada 2 cara praktis untuk menjalankan website ini di komputer lokal:

### Cara 1: Menggunakan File Batch (Paling Praktis)
1. Buka folder `Web Seminar PPG`.
2. Klik ganda (double click) file **`buka_web.bat`**.
3. Server lokal akan otomatis aktif dan membuka peramban (browser) ke alamat:
   ```
   http://localhost:8080
   ```

### Cara 2: Melalui Terminal / Command Prompt / PowerShell
1. Buka terminal pada folder ini (`d:\PPG\2_Semester 2\5_Seminar PPG\Web Seminar PPG`).
2. Jalankan perintah:
   ```bash
   python server.py
   ```
   *atau alternatif:*
   ```bash
   python -m http.server 8080
   ```
3. Buka peramban dan kunjungi: **`http://localhost:8080`**.

### Alternatif Tanpa Server (Direct File)
Anda juga dapat langsung mengeklik ganda file **`index.html`** atau file **`buka_langsung.bat`** untuk membuka website langsung di peramban web tanpa server.
